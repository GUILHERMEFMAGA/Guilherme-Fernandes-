## 🕹️ Pixel Tanks

Jogo de arcade em pixel art que vive neste repositório: HTML + Canvas puro, sem dependências.

- **Duelo** — melhor de 5 rodadas contra a CPU ou em 2 jogadores no mesmo teclado
- **Sobrevivência** — ondas infinitas, itens e recorde salvo no navegador
- Sprites, fonte bitmap e música chiptune **gerados por código** (nenhum arquivo de imagem/áudio)

▶️ **Como jogar:** abra [`pixel-tanks/index.html`](pixel-tanks/index.html) no navegador.
Funciona direto do disco, sem build e sem instalar nada.

```bash
# ou sirva por HTTP
python3 -m http.server 8000
# abra http://localhost:8000/pixel-tanks/
```

📖 Detalhes, controles e mapas: [`pixel-tanks/README.md`](pixel-tanks/README.md)
🧪 Testes (rodam no Node, sem navegador): `node pixel-tanks/test/headless.js`
